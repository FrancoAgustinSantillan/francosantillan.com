Pasé la web de HTML a mano a [Astro](https://astro.build). Ahora publicar es escribir un archivo `.md` y hacer `git push`.

Lo que cambió:

- Hay una sección de **proyectos**, cada uno con su ficha (estado, stack, links).
- Las **notas** pueden ser avances de un proyecto (como esta), notas sueltas o links.
- Cada proyecto muestra su propio diario con las notas que lo mencionan.
- Hay un feed [RSS](/rss.xml) para quien quiera seguir las novedades.
